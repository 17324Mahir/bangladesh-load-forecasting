# Auditable Next-Day Electricity Demand Forecasting in Bangladesh

This repository contains the research notebooks and experimental workflow for:

**"Auditable Next-Day Electricity Demand Forecasting in Bangladesh Using Data Auditing, Adaptive Conformal Calibration, and Locked-Test Evaluation"**

## Overview

This work presents a reliability-oriented framework for next-day electricity demand forecasting in Bangladesh. The notebook collection covers:

- Operational data auditing and quality assessment
- Data preprocessing and forecasting dataset preparation
- Exploratory data analysis (EDA)
- Machine learning and deep learning forecasting models
- Adaptive conformal prediction for uncertainty calibration
- BPDB cross-source consistency analysis
- Statistical ablation and robustness evaluation
- ERA5-based weather feature diagnostics
